# EBISUDA CHANNEL logo and character, high resolution

Exported from the designer's outlined vector artwork (Someya Isho Co., Ltd., 2021-02-18).
The original `.ai` / `.pdf` lives in OneDrive (hccjp) under `logo/`, with these exports in `logo/hd/`.

- `*.svg` / `*.pdf`: vector, scales without losing quality
- `*.png`: transparent, 2400 px tall (the circle icon is 2400x2400)
- `ebisuda-channel-logo-vertical` / `-horizontal`: the logo without the "あげ" lettering
- `ebisuda-channel-icon-circle`: the light-blue circle icon (PNG only; the circle clip does not survive vector export)
- `ebi-character-*`: character poses

Scale from the vector files. The 400 px PNGs in `Images/ebi/` blur when enlarged.
