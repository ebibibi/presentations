Windows Update の証明書が期限切れに
2027年5月17日・6月19日
証明書が古い端末は更新が届かなくなる
Source: https://techcommunity.microsoft.com/t5/windows-it-pro-blog/prepare-for-windows-update-certificate-rotation-in-2027/ba-p/4562463 / 2026年10月9日 ｜ ebisuda.net
--- Slide 2 ---
01
ANSWER
何をすればいい？
最新の月例更新を当てる
サポート中の Windows を最新に保てば、ほとんどの端末は対応不要 / 必要な更新を当てていない端末・サポート切れの端末は / Windows Update につながらなくなる
--- Slide 3 ---
02
WHY
なぜ「証明書」で更新が止まるのか
① 本物か確かめる
端末は証明書で / 「本物の Windows Update / サーバーか」を確認する
② 証明書には期限
安全のため有効期限がある / 期限が来たら新しい証明書へ / 交換（ローテーション）
③ 月例更新で配布
多くの端末には / 通常の月例更新で届く / 手動や管理ツールでも / 入れられる
新しい証明書が入っていない端末は、期限後に Windows Update へ接続できない

--- Slide 5 ---
04
AFTER EXPIRATION
期限を過ぎると、端末は3通りに分かれる
サポート中・最新
そのまま更新が届く /  / 新しい証明書は / すでに入っている
サポート中で未適用
必要な更新が未適用だと / Windows Update に / つながらなくなる /  / → 公式の更新カタログ / から手動で入れるか、 / 管理ツールで配る
サポート切れ
Windows Update を / 使えなくなる /  / → サポート中の版へ / アップグレード
--- Slide 6 ---
05
SCOPE
例外は？
WSUS 経由の端末は対象外
WSUS（社内サーバーから更新を配る仕組み）経由の端末には / 適用されない、と公式に明記 / 【私の提案】Windows Update に直接つなぐ端末を先に把握する
--- Slide 7 ---
06
CHECKLIST
今日確認する3項目（私の提案）
□1
古い Windows・サポート切れの Windows がどこにあるか洗い出す
□2
サポート中の端末に月例更新を当て続ける（更新を止めている端末を探す）
□3
サポート切れの端末のアップグレード計画を、2027年5月・6月の期限より前に立てる
