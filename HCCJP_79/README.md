## 概要

毎月第2金曜日14時からはHCCJPの勉強会！11月は Active Directory と Entra ID の間にある「あの待ち時間」の話です。

Entra ハイブリッド参加では、デバイスの情報が Entra Connect Sync で同期されるまで登録が終わりません。Autopilot で待たされる、条件付きアクセスに弾かれる、非永続VDIでは同期の前にマシンが消える。そして、デバイス同期のために Connect Sync を残し続けている環境もあります。

いまプレビュー中の Entra Kerberos によるハイブリッド参加は、この前提を変える仕組みです。オンプレADの Kerberos チケットを使ってデバイスを登録します。何が消えて、何が残るのか。Windows Server 2025 のDCが必要なのはなぜか。Autopilot のハイブリッド参加はクラウドネイティブになるのか。ややこしい「Entra Kerberos」という言葉の整理から始めて、仕組みと前提条件を読み解きます。

後半は毎月恒例、日本マイクロソフト 高添さんによる Microsoft "Adaptive Cloud" 最新動向です。
