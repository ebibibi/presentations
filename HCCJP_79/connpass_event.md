## セッション1：さよなら同期待ち — Entra Kerberosで変わるハイブリッド参加

**胡田 昌彦**（日本ビジネスシステムズ株式会社、Microsoft MVP）

Entra ハイブリッド参加では、デバイスの情報が Entra Connect Sync で同期されるまで登録が終わりません。
Autopilot で待たされる、条件付きアクセスに弾かれる、非永続VDIでは同期の前にマシンが消える。そして、デバイス同期のために Connect Sync を残し続けている環境もあります。

いま**プレビュー中の Entra Kerberos によるハイブリッド参加**は、この前提を変える仕組みです。オンプレADの Kerberos チケットを使ってデバイスを登録します。

- 「Entra Kerberos」という言葉が指す2つの話（ユーザー認証とデバイス登録）
- 従来のハイブリッド参加の流れと、同期待ちが生んでいた問題
- 新しい仕組みで不要になるものと、残るもの
- Windows Server 2025 のDCが必要なのはなぜか
- Autopilot のハイブリッド参加はクラウドネイティブになるのか
