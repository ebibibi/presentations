# 構成設計 — Active Directory入門 2026年版 Part 1

## 企画の位置づけ

- 2022年公開の人気動画 `lZ8Ps6U_kvY` を、2026年時点の情報と視認性で再構成する。
- 元動画の強みである「広い用語を一度に地図へ置く」を残す。
- 視聴者コメントの指摘を反映し、BGMなし、純黒背景なし、赤文字を本文に使わない。
- 1枚1メッセージ。スライドだけを順に見ても説明を再現できる構造にする。

## 想定視聴者

### 開始時点で知っていること

- Windowsへユーザー名とパスワードでサインインすること
- 会社のPCには「ドメイン参加」があるらしいこと
- DNSという言葉を聞いたことがあること

### 開始時点で知らないこと

- AD DSとMicrosoft Entra IDの違い
- フォレスト／ドメイン／OU／サイトが同じ軸の階層ではないこと
- DNS、Kerberos、LDAP、グループポリシーがどう連動するか
- ADデータベースとSYSVOLが別の仕組みで複製されること
- 2026年に注意すべきWindows Server 2025機能レベル、RC4、LDAP、DFSR

## スライドごとの問いと答え

1. 何を学ぶ？ → AD DSの用語を一枚の地図に置く
2. 何を改善した？ → BGMなし・高コントラスト・色だけに依存しない
3. ゴールは？ → 未知の用語を論理／物理／機能のどこかへ置ける
4. ADとEntraは同じ？ → 別のサービス。併用できる
5. AD DSとは？ → 組織内の共有名簿＋本人確認＋ルール配布
6. 何視点で見る？ → 論理構造／物理構造／提供機能。排他的分類ではなく重なりを許す
7. 何を保存する？ → ユーザー、PC、グループなどのオブジェクトと属性
8. オブジェクトの住所は？ → 識別名（DN）で階層を表す
9. フォレストとドメインは？ → フォレストが最上位、ドメインがデータ区画
10. 複雑に分けるべき？ → 特別な要件がなければ単純さを優先
11. ADドメインとDNSは？ → 同じ名前空間を使うが役割は別
12. なぜDNSが重要？ → DCと各サービスの発見に使う
13. SRVレコードとは？ → サービスの場所を知らせるDNSレコード
14. DCとは？ → ディレクトリを保持し認証などへ応答するサーバー
15. サイトとは？ → ネットワークの近さを表す物理構造
16. サイトリンクとは？ → サイト間複製の経路とコストを表す
17. OUとコンテナの違いは？ → OUは委任とGPOリンクに使える整理単位
18. OUとグループの違いは？ → OUは管理場所、グループは権限のまとまり
19. グループポリシーとは？ → PCとユーザーへ設定を配る仕組み
20. ドメイン参加とは？ → PCアカウントと安全なチャネルを作る
21. 認証方式は同列？ → Kerberos/NTLMとCredSSPは役割の層が違う
22. Kerberosはどう動く？ → チケットを使って各サービスへアクセスする
23. LDAPとは？ → ディレクトリを検索・更新するためのプロトコル
24. データはどこ？ → NTDS.ditとSYSVOLの二本立て
25. 複製とは？ → 多くの変更を複数DCへマルチマスターで反映
26. 削除はすぐ消える？ → 削除状態も複製し、Recycle Binは復元を助ける
27. スキーマとは？ → オブジェクト種類と属性を定義する森林全体の設計図
28. FSMOとは？ → 同時実行が危険な5処理だけ担当を一つに寄せる
29. 信頼関係とは？ → 別ドメインの認証結果を受け入れる経路
30. グローバルカタログとは？ → フォレスト全体を横断検索する索引
31. DCが複数ならバックアップ不要？ → 可用性と復旧は別
32. 健全性は何を見る？ → DNS、複製、時刻、SYSVOL、バックアップ
33. 2026年の更新点は？ → Server 2025、DFSR、Kerberos RC4、LDAP強化
34. 2026年のセキュリティ強化はどう進める？ → 監査して互換性問題を直し、段階的に強制する
35. 全体をどう覚える？ → ドメインを中心に、DNS・DC・認証・GPO・サイト・複製をつなぐ
36. 次に何をする？ → GUIとPowerShellで実物を確認する
37–38. 根拠は？ → 元動画とMicrosoft公式資料
