## 概要

毎月第2金曜日14時からはHCCJPの勉強会！9月は Azure Arc を「実際の運用に入れる」という話をします。

前回（第76回）は、オンプレのサーバーをその場で壊して、AIエージェントに直してもらいました。誰もそのサーバーにログインせず、VPNも踏み台もなしで、Azure 越しに調査から復旧まで通してしまう——Arc で繋いでおけば、オンプレの面倒くささはかなり消える、というところまではお見せできたと思います。

ただ、そこから「じゃあ本番でも使おう」に進むには、もうひとつ越える壁があります。「便利なのはわかった。で、壊れたらどうなるの？」

パッチを当てて壊れた。スナップショットで巻き戻した。バックアップから復元した。そのとき Azure 側はどうなっているのか。Azure から配った拡張機能や構成は自動で戻ってくるのか。ポータルに出ている緑の「正常」は、実機の何を保証しているのか。エージェントが繋がらなくなったら、現地に行かずに直せるのか。

公式ドキュメントを探しても答えが書かれていなかったので、実機（Windows Server 2025 / Ubuntu 24.04）で片っ端から確かめてきました。結果はきれいに自動で追いついたものと、追いついてこなかったものに、はっきり分かれています。

前半は Arc 経由で使える機能の棚卸し（統制／保護／構成／監視）と Azure Update Manager。2026年5月に追加費用ゼロになった Windows Server 2025 の Hotpatch の話もします。後半は「万が一」を実際に起こして、戻し方のチェックリストを持ち帰っていただく構成です。

「じゃあ運用に Arc 入れてもいいね」と言えるようになる回にします。
